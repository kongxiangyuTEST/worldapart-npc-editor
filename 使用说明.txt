========================================
  WorldApart 人物卡编辑器  v0.4
========================================

一款给游戏《不问凡尘》用的 AI 对话辅助编辑器。
通过本地中转层，把你在编辑器里写的"用户名片"
注入到游戏发给 AI 的提示词里，让游戏里 NPC 的
对话体现出你写的设定。

【一、运行前需要准备什么】
----------------------------------------

1) Windows 10 / 11

2) Microsoft Edge WebView2 运行时
   （Win10/11 新版本一般自带；如果编辑器打不开，
   去微软官网搜 "WebView2 Runtime" 下载安装）

3) 本地大模型服务
   （如 llama.cpp 的 llama-server，监听 8080 端口）
   或者，你打算用第三方 API（如 DeepSeek）

4) 游戏《不问凡尘》已安装

5) （可选）AssetStudioModCLI.exe
   用于"导出角色卡"和"提取头像"。
   下载：https://github.com/aelurum/AssetStudio/releases
   （找文件名带 CLI 的压缩包）
   不装也能用编辑器，但没法自动生成卡片和头像。


【二、首次使用】
----------------------------------------

1) 双击 WorldApartEditor.exe 启动编辑器

2) 编辑器会弹出"选择游戏目录"窗口，
   选 WorldApart.exe 所在的文件夹

3) 编辑器自动启动 core_proxy 和 caddy，不用手动开

4) 进"工具"页，顶部有开关：
      提取头像  /  导出角色卡
   两者共用下面的"CLI 路径"和"游戏目录"，填一次就行。
   点"开始提取 / 开始导出"，等几分钟

   （两个输入框旁边有"选择文件 / 选择文件夹"按钮，
   会记住上次打开的位置，下次不用从根目录翻）

5) 数据都存在 exe 同级的文件夹里（换电脑、分享给别人时各存各的，
   不会串到别人机器上）：
      memory\          每个角色的长期记忆
                       进"长期记忆"页，左下角会显示当前实际路径，
                       点"打开"可直接打开
      editor_cards\    NPC 卡片
      prompt_samples\  游戏真正发给 AI 的提示词样本
      originals\       卡片原版备份（"恢复原版"用）
      last_saved\      上次保存的备份（"撤销修改"用）

（如果游戏换位置了，到"服务管理"页最上方点"修改"重新指定游戏目录）


【三、游戏里要填什么】
----------------------------------------

打开游戏 → 自定义 AI 模型设置 → 填写：

  接口地址：http://127.0.0.1:8788/v1/chat/completions
  API Key ：按你实际使用的上游填
  模型名称：按你实际使用的上游填
  上下文长度：按你实际使用的上游填

  提示：编辑器"服务管理"页可以一键复制接口地址。

  关于 API Key：编辑器里不需要填密钥。
  对话用的 key 来自游戏这里的设置，编辑器只负责原样转发；
  "core_proxy_config.json" 里的 api_key 只是游戏没带 key 时的兜底，
  平时留空就行。


【四、上游与模型分工（重点）】
----------------------------------------

编辑器 → 服务管理 → "上游地址"：

  本地 8080 ：http://127.0.0.1:8080/
  DeepSeek ：https://api.deepseek.com/
  OpenAI   ：https://api.openai.com/

改完点"保存并重启 core_proxy"生效。
注意：切到第三方 API 后，游戏里的 API Key 也要换成第三方的，
否则会报 401。

同一页下半部分是"记忆总结"设置，可以**和对话用不同的模型**：

  记忆总结地址：留空 = 跟随上游；
               想让总结走本地就填
               http://127.0.0.1:8080/v1/chat/completions

推荐组合：
    对话  → 第三方 API（效果好）
    总结  → 本地模型（不花钱、对话内容不出本机）

这块还有五个控件：
  记忆落位        system 末尾（默认，省缓存）/ 写进游戏"过往要事"
  过往要事上限    800 字，0 = 不压缩
  合并频率        每 12 轮自动总结一次
  输出上限        4000 token（太小会被截断成非法 JSON）

  这五个改动后**失焦即自动保存**，不用特意点保存。
  （以前忘了点保存会静默失效，现在不会了）


【五、用户名片怎么写（核心功能）】
----------------------------------------

卡片里"## 用户名片"这一段的内容，会被整段注入到游戏
发给 AI 的提示词末尾，标题是"## 角色演绎要求"。
位置在最后，离生成位置最近，权重最高。

推荐结构（四节）：

  ### 口吻
  - 基调：整体什么味道
  - 句长：长句还是短句
  - 自称：她怎么称呼自己
  - 称谓：她怎么称呼玩家
  - 口头禅：2~3 个
  - 小动作：2~3 个

  ### 行为逻辑
  - 当「什么情况」→ 则「她怎么反应」
  - 当「什么情况」→ 则「她怎么反应」

  ### 绝不说
  - 不用"作为一个…"这类自我指涉
  - 不复述玩家刚说过的话
  - 不总结对方的情绪
  - 不排比抒情

  ### 示例台词
  1. 「她真的会这么说的一句话」
  2. 「……」
  3. 「……」

**示例台词最管用。** 写 2~3 句她会说的话，比写两百字
形容词有效得多。

两种写法：

  1) 点名片区右上角的「插入结构模板」
     —— 一键铺出上面的骨架，自己填

  2) 点「AI 补全名片」
     —— 读取卡片背景 + 游戏 prompt + 长期记忆，自动生成

     AI 补全弹窗里可以：
     · 选「本地模型」或「跟随上游 API」
     · 填一段"人设原稿"（最高优先级，按你写的来）
     · 勾选要不要读游戏样本和长期记忆

     生成后先给你看，可以在框里改，点「填入名片」才写进去，
     **不会自动保存、不会自动覆盖**。

     它按"游戏原始资料"为准：卡片预设与原游戏背景优先，
     玩家在对话里说过的话、自称的身份、临时编的剧情，
     都不会被当成设定依据（避免玩家把 NPC 人设带偏）。


【六、长期记忆】
----------------------------------------

每轮对话会记进该角色的记忆队列，满 12 轮由 AI 总结成
剧情摘要。过时的事实按重要度分级、逐级降级、最后遗忘。

"长期记忆"页能做的事：

  · 左上选角色，右边显示时间地点 / 早期梗概 / 最近剧情 / 四类事实
    （赠物 / 承诺 / 关系里程碑 / 重要事件）

  · 点「🤖 立即 AI 总结」—— 不等满 12 轮，现在就总结

  · 如果攒了对话还没总结，页面顶部会有黄色提示条，
    告诉你攒了多少字 / 多少轮，点一下就能生成

  · 总结失败时不会丢对话：内容会退到文件里，
    提示条会显示失败次数和原因（比如地址不对、模型没开）

  · 「当前时间地点」由每次总结自动填写，也可以自己改

  · 选中角色后，如果文件被 core_proxy 改过，详情会自动刷新

  · 换存档保护：如果游戏记录和记忆对不上（像是换了档），
    会暂停注入并出现横幅，让你确认是"同一档"还是"新档"


【七、AI 提示词页】
----------------------------------------

五个标签页：

  1) 用户名片 —— 总开关，关掉就完全不注入名片

  2) INJECT 注入 —— 每轮追加到提示词里的一整段话

  3) REPLACE 替换规则 —— 把游戏原文里的某句话换成另一句。
     默认 12 条，只作用于游戏的 system 部分。
     改完存盘即生效，不用重启。

  4) 预览效果 —— 选一个真实样本跑一遍，
     看命中了几条规则、注入了多少字、最终提示词长什么样

  5) 固定段落 —— 从样本里统计出"每轮都一样"的段落。
     点「让 AI 精简」，它会合并同义句、删赘述，
     给你看省了多少字和风险等级；
     点「采用为替换规则」就变成一条规则，
     之后这一段会一直显示「已用精简版替换（第 N 条）」，
     想退回点旁边的「恢复原设定」即可。

     注意：像"本轮会话状态""当前场景"这种每轮都在变的段落，
     会标记成"不能做替换规则"——规则做了也立刻失效。

底部只有两个按钮：「放弃更改」和「保存并生效」。
点保存后会：
  1. 写盘
  2. 自动问一次服务，确认配置真的生效了
     （显示"✓ 已保存并生效 · 12 条规则 / 注入 108 字"）
  3. 万一服务里还是旧的，会自动重启一次再复查
  4. 在"预览效果"页保存时，还会按新配置自动重跑一次预览

再也不用单独点"重启 core_proxy"了（上游地址除外，那个必须重启）。


【八、工具页】
----------------------------------------

标签 1：提取
  顶部开关切换「提取头像」和「导出角色卡」，共用下面两个输入框。
  · 提取头像   → 从游戏资源解出 NPC 头像
  · 导出角色卡 → 从游戏数据生成 NPC 卡片
  耗时几分钟，进度看"日志"页，可中途"中止"。
  「保留中间文件」是调试用的。

  ⚠ 重要：从游戏重新导出角色卡会**清空你已经写的用户名片**
  （导出功能永远写的是空名片模板）。导出前编辑器会自动
  做一次全量备份到 editor_cards_backup\<时间戳>\，
  要找回就从那里复制回来。

标签 2：卡片对比
  选一份备份，和当前卡片比，列出新增 / 改动 / 删除。
  点「应用改动」会合并：游戏字段用新版，**用户名片保留**。
  合并前还会再备份一次。

标签 3/4：批量工具、导入导出 —— 占位，暂未实现。

三个路径选择框都会记住上次打开的位置，下次直接到那儿。

----------------------------------------

【十一、常见问题】
----------------------------------------

Q: 编辑器打不开？
A: 装 WebView2 运行时。

Q: 卡片列表是空的？
A: 还没导出过卡片。去"工具 → 提取 → 导出角色卡"跑一次。

Q: 头像不显示？
A: 去"工具 → 提取 → 提取头像"跑一次。

Q: 改了名片，游戏里还是老样子？
A: 按顺序查：
   1. 名片里真的有内容（不是空模板）
   2. "AI 提示词 → 用户名片"开关是开着的
   3. core_proxy 在运行（看"服务管理"页）
   4. 到"预览效果"看"名片字数"是不是 0
      —— 是 0 说明没匹配到这张卡（NPC 名字没解析出来）

Q: 游戏里 AI 没反应 / 502？
A: 检查：
   1. 本地大模型服务（llama-server）在运行，
      或上游地址填的是正确的第三方 API
   2. 游戏里接口地址填的是
      http://127.0.0.1:8788/v1/chat/completions

Q: 点"立即 AI 总结"报 401？
A: 401 = 没授权，基本都是总结打到了第三方 API 却没带对 key。
   看报错里的地址就能确认。
   处理：到"服务管理 → 记忆总结"填本地地址，
   现在改完失焦就自动保存了。

Q: 总结报 502 / 连不上？
A: 本地模型（8080）没开。启动 llama-server 再试。

Q: 角色开始翻来覆去说同样的话？
A: 三个方向：
   1. 到记忆页看事实有没有重复堆积（现在会自动去重）
   2. 看"最近剧情"是不是在照抄对话原文
   3. 名片里的示例台词是不是太文雅 —— 改短、改口语

Q: "当前时间地点"一直是空的？
A: 那个字段是每次 AI 总结时由模型填写的。
   没总结过就是空的，手动填也行。

Q: 服务一直显示"未运行"、日志空白？
A: 有残留进程占着端口。到"服务管理"全部停止后重启；
   还不行就手动结束 core_proxy / caddy 进程。

Q: 游戏更新后，我写的"用户名片"会丢吗？
A: 正常流程不会：导出 → 卡片对比 → 应用改动，
   编辑器只更新游戏数据，保留用户名片。
   但如果直接覆盖或重新导出又没走对比，就会被清空 ——
   所以一定要先备份（编辑器会自动备份）。
