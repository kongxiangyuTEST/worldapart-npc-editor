========================================
  WorldApart 人物卡编辑器  v0.2
========================================

一款给游戏《不问凡尘》用的 AI 对话辅助编辑器。
通过本地中转层，把你在编辑器里写的"用户名片"
注入到游戏发给 AI 的提示词里，让游戏里 NPC 的
对话体现出你写的设定。


【一、运行前需要准备什么】
----------------------------------------

1) Windows 10 / 11

2) Microsoft Edge WebView2 运行时
   （Win10/11 新版本一般自带；如果编辑器打不开，
   去微软官网搜 "WebView2 Runtime" 下载安装）

3) 本地大模型服务
   （如 llama.cpp 的 llama-server，监听 8080 端口）
   或者，你打算用第三方 API（如 DeepSeek）

4) 游戏《不问凡尘》已安装

5) （可选）AssetStudioModCLI.exe
   用于"从游戏导出角色卡"和"提取头像"。
   下载：https://github.com/aelurum/AssetStudio/releases
   （找文件名带 CLI 的压缩包）
   不装也能用编辑器，但没法自动生成卡片和头像。


【二、首次使用】
----------------------------------------

1) 双击 WorldApartEditor.exe 启动编辑器

2) 编辑器会弹出"选择游戏目录"窗口，
   选 WorldApart.exe 所在的文件夹

3) 编辑器自动启动 core_proxy 和 caddy，不用手动开

4) 进"工具 → 导出角色卡"，填 AssetStudioModCLI 路径，
   点"开始导出"，等几分钟，生成 NPC 卡片

5) 进"工具 → 头像提取"，同样填好路径，点"开始提取"，
   等几分钟，生成头像

（如果游戏换位置了，到"服务管理"页最上方点"修改"
重新指定游戏目录）


【三、游戏里要填什么】
----------------------------------------

打开游戏 → 自定义 AI 模型设置 → 填写：

  接口地址：http://127.0.0.1:8788/v1/chat/completions
  API Key ：按你实际使用的上游填
  模型名称：按你实际使用的上游填
  上下文长度：按你实际使用的上游填

  提示：编辑器"服务管理"页可以一键复制接口地址。


【四、切换上游（本地大模型 / 第三方 API）】
----------------------------------------

编辑器 → 服务管理 → "上游地址"：

  本地 8080 ：http://127.0.0.1:8080/
  DeepSeek ：https://api.deepseek.com/
  OpenAI   ：https://api.openai.com/

改完点"保存并重启 core_proxy"生效。

  注意：切到第三方 API 后，游戏里的 API Key
       也要换成第三方的 key，否则会报 401。


【五、游戏更新后怎么同步卡片】
----------------------------------------

游戏更新后，NPC 数据可能变了。编辑器有"对比"功能：

1) 进"工具 → 导出角色卡"，点"开始导出"
   （编辑器会先备份上一次的卡片，再导出新的）

2) 进"工具 → 卡片对比"，选一个备份，点"开始对比"

3) 看差异：
   - 新增：游戏里加了新 NPC
   - 改动：某 NPC 的背景/属性变了
   - 删除：游戏删了某 NPC

4) 点"应用改动"，编辑器会把新数据合并进卡片，
   同时保留你写过的"用户名片"

  注意：合并前会自动备份，所以不怕操作失误。


【六、关闭顺序】
----------------------------------------

1) 关闭编辑器 → core_proxy 和 caddy 自动停止
2) 关闭本地大模型服务（如果用了）


【七、常见问题】
----------------------------------------

Q: 编辑器打不开？
A: 装 WebView2 运行时。

Q: 卡片列表是空的？
A: 还没导出过卡片。去"工具 → 导出角色卡"跑一次。

Q: 头像不显示？
A: 去"工具 → 头像提取"跑一次。

Q: 改了卡片，游戏没反应？
A: 检查三点：
   1. 卡片里"用户名片"区块有内容
   2. 编辑器"AI 提示词 → 用户名片"开关是开着的
   3. core_proxy 在运行（看"服务管理"页）

Q: 游戏里 AI 没反应 / 502？
A: 检查：
   1. 本地大模型服务（llama-server）在运行
      或上游地址填的是正确的第三方 API
   2. 游戏里接口地址填的是
      http://127.0.0.1:8788/v1/chat/completions

Q: 切到第三方 API 后报 401？
A: 游戏里的 API Key 没换。切上游后，
   游戏里的 key 也要换成对应平台的。

Q: 游戏更新后，我写的"用户名片"会丢吗？
A: 不会。只要用"工具 → 导出角色卡"重新导出，
   再"卡片对比 → 应用改动"，编辑器会自动
   保留你写的用户名片，只更新游戏数据。
