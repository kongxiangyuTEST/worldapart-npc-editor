# 参考音电平归一化（2026-10-30）

> **这条是隐性依赖，换机器 / 重装 MOD / 做分享包前必须知道。**

## 一句话

`A1IndexTTSMod/references/npcs/` 下 1169 个角色参考音，已被批量改过振幅（统一响度 + 峰值封顶 −3 dBFS）。原始文件完整备份在同级 `npcs_backup/`。

## 为什么改

用户实测反馈「声音大时稍稍破音，混着人机噪」。查 `stage3-audio` 里的合成输出，发现其中一条：

```
reply-000006.wav  峰值 0.0 dBFS  削波采样点 11 个  RMS -13.9
```

顶到满刻度，采样被截平，就是破音。

根因链：

```
抽样 147 条参考音 → 32% 峰值高于 -3 dBFS（中位 -3.5，最响 -0.4）
Breeze 合成再抬高 2~3 dB
→ 顶到 0 dBFS，削波
```

Breeze 不做限幅，MOD 链路闭源改不了，代理不接触音频数据。**唯一能动手的地方是参考音电平。**

关键实测（说明这条路有效）：

| 参考音峰值 | 合成输出峰值 |
|---|---|
| −1.7 dBFS | −3.1 dBFS |
| −7.8 dBFS（人为降 6 dB） | −12.4 dBFS |

参考音降 6.1 dB，输出降 9.3 dB —— 是放大的关系，所以归一化参考音能有效控制输出峰值。

## 做了什么

脚本 `tools/normalize_references.py`：

1. RMS 归一到 −20 dBFS（统一响度，避免有的 NPC 天生偏轻）
2. 峰值封顶 −3 dBFS（防削波，留 3 dB 给合成抬升）
3. 取两者较小增益：`min(g_rms, g_peak)`

只改振幅，不动采样率、位深、声道数、文件头。频谱不变，音色不受影响。

执行结果：

```
1169 条 → 改动 947 条（变响 610 / 变轻 337）
增益中位 +0.6 dB，范围 −5.6 ~ +4.9
处理后：峰值中位 −3.0、最高 −2.9、自身削波 0 条
       RMS 中位 −22.7（范围 −24.8 ~ −20.0）
```

验证（8896 独立端口实测，不动 MOD 的 8893）：

| 参考音 | 参考峰值 | 输出峰值 | 削波 |
|---|---|---|---|
| 100221 | −6.7（原 −1.7） | −7.0 | 0 |
| 100121 | −3.6（原 −4.6） | −6.6 | 0 |

输出落在 −7 dBFS 左右，离 0 有 7 dB 余量。

## 怎么还原

```bash
cp "A1IndexTTSMod/references/npcs_backup/"*.wav "A1IndexTTSMod/references/npcs/"
```

或者重新跑脚本换目标值：

```bash
.venv\Scripts\python.exe tools/normalize_references.py --dry-run   # 只看统计
.venv\Scripts\python.exe tools\normalize_references.py --apply     # 执行（自动备份）
```

觉得整体偏轻，可以把 `PEAK_CEIL` 从 `-3.0` 放宽到 `-2.0`，响度回来 1~2 dB，削波风险仍低。

## 注意事项

- **工坊装包不会覆盖**：`Install.ps1` 对 `references\` 下已存在的文件是 `continue` 跳过，所以工坊更新 MOD 时归一化版本会保留
- **重装 MOD 会丢**：手动删过 `references/` 或换机器重装，需要重跑脚本
- **分享包要带脚本**：如果把这套参考音打进分享包，必须附带 `tools/normalize_references.py` 和本文档，否则用户不知道为什么音量偏轻
- **不影响 `references/` 根目录**：`demo.wav`、`default_male.wav`、`default_female.wav` 未处理，只动了 `npcs/` 子目录

## 已知未解决

用户反馈的「底层合成感、低沉」**未定位**。中途怀疑是 2 kHz 能量衰减，但后续发现：

- 同参考音、不同文本的合成输出，2 kHz 能量差 3 倍（0.14 vs 0.04~0.07）
- 所以无法跨文本比较频谱，之前的诊断结论不成立
- 预加重实验（参考音提前提高频 +3/+6 dB）无规律，已放弃

要重查必须固定同一句台词做参考音 vs 合成输出的频谱对照。目前怀疑是 Breeze 24 kHz 轻量模型的音质上限。
