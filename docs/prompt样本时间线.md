## 自主测试期（2026-10-29 02:53 起）

用户会自己反复切换语音包试听，**不再逐次告知**。这批样本的特征：

- 引擎可能在 Breeze（v2 / 8893）与 CosyVoice3（v1 / 8892）之间来回切
- 可能开关 `proxy_passthrough`、`tts_style_auto_perf`、`tts_instruct_override`
- **不能默认任何一条样本属于哪个模式**

判定方法（按可靠性排序）：

1. 读当时的 cfg 与 ai_config —— 但都会随用户操作变化，事后无法还原
2. 看 `proxy/tts_decisions.log` 的 `instruct=` 字段 —— 能反映当时生效的角色基线
3. 看 BepInEx 日志的 `TTS cold switch succeeded: <V1|V2> / <engine>` —— 引擎切换时会记
4. 看 `a1ttsv2` 出现率 —— 仅对透传期有效，引擎切换期不适用

**结论：02:53 之后的样本默认不可用于「注入效果」统计**，除非能同时拿到当次运行的模式证据。要用于对比，必须先在 `tts_decisions.log` 里定位到对应时间戳的 instruct 记录。
