WorldApart 人物卡编辑器

版本 0.2
这是什么
游戏《不问凡尘》（WorldApart）的 AI 对话辅助编辑器。它让你在游戏外编辑 NPC 的"用户名片"，并通过本地中转层把内容注入到游戏发给 AI 的提示词里，让游戏里 NPC 的对话体现出你写的设定。
主要功能
· 编辑 NPC 人物卡（用户名片、预设资料、原游戏背景）
· 用户名片注入，影响游戏里 NPC 的回复
· 撤销 / 恢复原版，改动随时回退
· 查看游戏实际发给 AI 的完整 prompt
· AI 提示词管理（INJECT 注入 + REPLACE 替换规则）
· 内置 Caddy + core_proxy 启停和日志
· 从游戏直接导出角色卡（不依赖 Mod）
· 从游戏资源里提取 NPC 头像
· 卡片对比（游戏更新后看新增 / 改动 / 删除）
· 合并改动（游戏字段用新版，用户名片保留）
· 上游地址切换（本地大模型 / 第三方 API）
工作原理
游戏发对话请求 → Caddy 8788 转发 → core_proxy 8789 拦截 → 提取 NPC 名字、读取对应 .md 卡片、把"用户名片"注入 prompt → 转发给上游（本地 8080 或第三方 API）→ AI 回复 → 游戏显示。
卡片来源
编辑器从游戏本体的 assets/luban/data/tbnpcbasecfg.json 等表里解析出 NPC 数据，生成卡片到 editor_cards\。整个过程不依赖游戏侧的 Mod，纯编辑器本地操作。
技术栈
Python 3.10 + pywebview（桌面壳）
Flask（core_proxy 代理）
Caddy（转发层）
纯 HTML / CSS / JavaScript（前端，无框架）
