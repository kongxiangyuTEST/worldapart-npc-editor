ABOUT

WorldApart 人物卡编辑器

版本 —
这是什么
游戏《不问凡尘》（WorldApart）的 AI 对话辅助编辑器。它让你在游戏外编辑 NPC 的"用户名片"，并通过本地中转层把内容注入到游戏发给 AI 的提示词里，让游戏里 NPC 的对话体现出你写的设定。
主要功能
· 编辑 NPC 人物卡（用户名片、预设资料、原游戏背景）
· 用户名片注入，影响游戏里 NPC 的回复
· 长期记忆：自动总结剧情、重要度分级、按轮次老化遗忘
· 记忆写进游戏自带的「过往要事」段，system 里只留一处
· 换存档保护：游戏记录对不上时自动暂停注入，确认后恢复
· 记忆按预算注入，关系里程碑永远优先保留
· 提示词预览：改完规则立刻看到最终 system 与命中条数
· AI 提示词管理（INJECT 注入 + REPLACE 替换规则），存盘即生效
· 查看游戏实际发给 AI 的完整 prompt（真实对话样本）
· 内置 Caddy + core_proxy 启停和日志
· 从游戏直接导出角色卡（不依赖 Mod）
· 从游戏资源里提取 NPC 头像
· 卡片对比（游戏更新后看新增 / 改动 / 删除）
· 合并改动（游戏字段用新版，用户名片保留）
· 撤销 / 恢复原版，改动随时回退
· 上游地址切换（本地大模型 / 第三方 API）
· 名片结构化：口吻 / 行为逻辑 / 绝不说 / 示例台词，一键插入模板
· AI 补全名片：读游戏原始资料自动生成，可切本地模型或 API
· 记忆总结可单独走本地模型（对话走 API、总结留本地）
· 固定段落 AI 精简：把每轮重复的长段落压缩，省 token
· 记忆总结失败不再丢对话，页面直接提示积压量与原因
工作原理
游戏发对话请求 → Caddy 8788 转发 → core_proxy 8789 拦截 → 从「角色设定」里解析 NPC 名字 → 读取 .md 卡片与长期记忆 → 依次执行替换规则、注入记忆、注入用户名片 → 转发给上游（本地 8080 或第三方 API）→ AI 回复 → 游戏显示。
用户名片作为「角色演绎要求」追加在 system 末尾，离生成位置最近、权重最高；记忆总结可单独指向本地模型，对话仍走 API。
回复到达后，本轮对话会写进该角色的记忆队列；积累到一定轮数由 AI 自动总结成剧情摘要，过时的事实按重要度逐级降级、最终遗忘。
数据存放
editor_cards\ NPC 卡片 · memory\ 长期记忆 · prompt_samples\ 真实对话样本 · originals\ 原版备份
全部在程序同级目录，换电脑或分享给别人时各存各的，不会互相串。记忆页左下角会显示当前实际路径。
卡片来源
编辑器从游戏本体的 assets/luban/data/tbnpcbasecfg.json 等表里解析出 NPC 数据，生成卡片到 editor_cards\。整个过程不依赖游戏侧的 Mod，纯编辑器本地操作。

· 修复替换规则长期不生效（此前只对玩家发言做替换，而原文写在 system 里）
· 规则匹配增加兜底，配置存盘即生效，不用再重启 core_proxy
· 新增提示词预览：看到命中几条、注入了多少字、最终 system 长什么样
· 长期记忆重做注入预算，摘要不再被腰斩，关系里程碑受保护
· 记忆读写加锁 + 写盘前自动备份，避免后台总结覆盖正常记录
· 修复服务残留进程抢端口，导致状态一直显示"未运行"、日志空白
· 长期记忆改写进游戏自带的「过往要事」段，不再在 system 末尾另贴一段
· 新增换存档保护：读到另一份存档时暂停注入，等你确认是"同一档"还是"新档"
· 界面全面换新，路径全部跟随程序目录，可直接分享
0.5.3 更新
· 修复：AI 补全名片、提示词压缩调本地模型时报 404 —— 请求里的模型名 写死成 local-model，Ollama 严格校验模型名，找不到就拒。现在读你配置的模型名， 留空则自动向服务要一个
· 修复：补全名片和试聊的请求会被加速器的系统代理拦掉（内网地址）， 现在对内网自动不走代理
· 新增：注入规则页「导入配置」—— 粘贴别人分享的 JSON 直接合并导入， 不用一条条手填
· 模型报错时给具体建议（404 是地址还是模型名、401 是密钥、5xx 去看服务端日志）， 不再只丢一个状态码
0.5.2 更新
· 修复：注入语里的替换规则会在保存配置时被清空 —— 各页面只管自己那部分字段， 保存时没传的字段被一起抹掉了。现在改成合并保存，只更新你改的那部分
· 修复：重新打测试包时，测试包里改过的注入配置会被项目目录的旧版本覆盖。 现在测试包已有配置就保留
· 打包脚本里的双重换行符清理掉，命令行偶发执行异常的问题一并修了
0.5.1 更新
· 修复：把模型地址填成局域网里另一台机器（比如 Mac 上跑的 Ollama）后用不了， 一直报 404 —— 加速器的系统代理会把发往内网 IP 的请求拦掉， 现在对内网地址自动不走代理
· 记忆总结的等待时间从 60 秒放宽到 240 秒：模型第一次加载就要几十秒， 原来那个超时经常等不到结果
· 更新页的检查更新支持填代理（HTTP / SOCKS5），填一次就记住
0.5 更新
· 新增「试聊」页：不启动游戏就能用真实卡片 + 长期记忆 + 游戏段落跟模型对话， 验证改完的设定说话像不像样；支持本机 Ollama 和任意 OpenAI 兼容地址
· 新增「更新」页：自动检测新版本，一键下载并原地更新。 只覆盖程序文件，卡片 / 记忆 / 调过的配置一律不动，覆盖前自动备份
· 语音 MOD 兼容：配合 A1IndexTTSMod 让 NPC 真的说出声 —— 注入台本要求、保住模型输出的台本字段、模型漏输出时从对白兜底补写
· 打包分成两种：正式包（干净，分享用）和测试包（带上你的卡片与记忆）
· 试聊 / 记忆总结都支持走局域网另一台机器上的模型，不占用本机
0.4 更新
· 用户名片升级为结构化设定（口吻 / 行为逻辑 / 绝不说 / 示例台词）， 注入标题改为「角色演绎要求」并挪到 system 末尾，人设更容易生效
· 新增 AI 补全名片：读卡片背景 + 游戏 prompt + 长期记忆自动生成， 模型可选本地或 API，以游戏原始资料为准，玩家发言不会被当成设定

· 提示词页底部合并为「保存并生效」，保存后自动验证配置是否真生效
· 固定段落支持 AI 精简，采用后一键变成替换规则，可随时恢复原设定
